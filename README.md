## 每周更新提案

- 每周一北京时间 **09:17** 检查作者的 `main` 分支。GitHub 调度可能稍有延迟。
- 指南有变化时，自动创建或更新同一条 PR，包含版本链接和文件变化统计；由你查看后决定是否合并。
- 指南没有变化时，不创建提案，也不更新同步日期。
- 只同步 `guides/how-to-live-better/`、版本记录及来源说明中的同步区块。个人规划与笔记请放在指南目录以外。
- 如果指南目录被手工改动，任务会停止，避免覆盖批注；自动更新分支由任务维护，请在自己的分支或笔记目录写内容。
- 原项目内的脚本与工作流仅作为资料保存，同步任务不执行它们。

需要提前检查时，打开 [Actions 工作流](https://github.com/kong-tiaoz/life-planning/actions/workflows/sync-life-guide.yml)，点击 **Run workflow**。更新提案在 [Pull requests](https://github.com/kong-tiaoz/life-planning/pulls) 中查看。

GitHub 可能在公开仓库连续 60 天没有活动时暂停定时工作流。若看到停用提示，在 Actions 页面重新启用后即可恢复。检查失败时，可在同一页面查看错误记录；任务不会把失败的更新直接合入 `main`。
